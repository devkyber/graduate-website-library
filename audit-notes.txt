Graduate website reference library — checked 29 October 2026

2459 unique personal websites; 72 institutions; 587 visual shortlist picks; 1414 matched public website repositories.

This update adds 178 personal websites to the recorded baseline of 2281. The starting artifact contained 2,281, rather than the 2,282 mentioned in the request. See expansion-report.json for exact university changes and updated existing profiles.

Discovery and eligibility
Personal links were discovered through university lab and research-group rosters, sometimes through an exact link on a member profile. Source chains are preserved. Current graduate affiliation was checked against those sources and the personal biography. A newer completed-degree, undergraduate-only, or postdoctoral/employment-only biography was grounds for exclusion. Prior lab discovery can lead to a graduate at another institution; current affiliation is shown. A small number of earlier entries explicitly on graduate-study leave remain labeled.

Visual selection
Every included site has a rendered desktop screenshot review. New additions received fresh visual review and specific design observations. Readable conventional academic layouts are included alongside distinctive portfolios; design picks highlight stronger visual ideas. This is not a complete mobile or accessibility audit of external sites. The separate top-100 editorial ranking is preserved from the earlier collection and has not been reranked against these new additions.

Repositories
GitHub Pages matches use public repository identity and enabled Pages, or matching public website source files. Custom-domain matches use CNAME files, explicit source links, or matching source content. Per-entry matching evidence is recorded. General GitHub profiles are separate from website repositories. Where no license was recorded, the interface says so; screenshots and linked content belong to their authors.

Quality and limits
URLs, resolved URLs, and names within an institution were reconciled. Existing IDs remain stable. Moved sites update an existing person instead of increasing the count. New sites with placeholder content, broken rendering, or unsupported graduate status were excluded. Older entries retain their earlier checks unless listed as updated; this expansion did not revalidate every external link in the whole collection. Public pages can change after review.

Coverage is broad, not an assertion that every lab was visited. The five focus institutions are Stanford, MIT, Harvard, UC Berkeley, and Caltech, reflecting the original request. The Caltech pass found no additional eligible personal sites; its total stays 60, below the original per-university target of 100. The overall target of at least 2,000 remains met.

Browse graduate-website-library.html locally, or the public GitHub Pages index.html. all-links.txt contains named links; website-urls-only.txt contains one URL per line. source-register.json contains provenance, screenshot paths, and repository matches. new-additions.json and new-additions-links.txt isolate the new material.
