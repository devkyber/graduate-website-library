# Graduate website reference library

A visual reference library of **2,281 graduate-student personal websites**, discovered through university labs and research groups. Prepared for design inspiration, with website links, screenshots, source trails, and verified website repositories where available.

- **[Explore the ranked top 100](https://devkyber.github.io/graduate-website-library/top-100/top-100-graduate-websites.html)** — fresh large screenshots, design observations, and practical ideas to adapt

The gallery can also be downloaded with **Code → Download ZIP** and opened locally using `index.html`. Keep the image folders beside the HTML files.

## Collection

- 2,281 unique personal websites across 72 institutions
- 521 visually selected design examples
- 1,309 verified public website repositories
- A separate editorial top 100, with 100 full-size desktop screenshots and 51 website repositories

The current expansion prioritizes Stanford, MIT, Harvard, UC Berkeley, and Caltech. University prestige is not used to rank designs. Graduate affiliation and lab provenance are checked against public pages; pages can change after the recorded review date. The collection includes both distinctive portfolios and conventional academic websites.

## Provenance and review

Every entry preserves a lab/group discovery trail. Screenshots were visually reviewed, and duplicate URLs, redirects, and names were reconciled. The top-100 ranking compares composition, typography, visual coherence, distinctiveness, and usefulness as inspiration. See [audit notes](audit-notes.txt) and [top-100 verification](top-100/verification.json) for scope.

Screenshots and linked website content belong to their respective owners. Repository links identify the website's source where verified; a profile link is not treated as a source-code match.

This static collection uses no analytics and requires no account. Saved favorites remain in your own browser's local storage.
