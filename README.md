# Graduate website reference library

A visual reference library of **2,459 graduate-student personal websites**, discovered through university labs and research groups. Prepared for design inspiration, with website links, screenshots, source trails, and verified website repositories where available.

## Collection

- 2,459 website reference records across 72 institutions
- 587 visually selected design examples
- 1,422 records with verified public website repositories
- A separate editorial top 100, with 100 full-size desktop screenshots and 53 website repositories, representing 33 institutions

The current expansion adds 178 websites to the recorded 2,281-site baseline and prioritizes Stanford, MIT, Harvard, UC Berkeley, and Caltech. Caltech remains at 60 after a further source review; no additional qualifying sites were added there. University prestige is not used to rank designs. Graduate affiliation and lab provenance are checked against public pages; pages can change after the recorded review date. The collection includes both distinctive portfolios and conventional academic websites. The top 100 was reranked across all 2,459 records on 2026-10-29, including the new additions.

## Provenance and review

Every entry preserves a lab/group discovery trail. Screenshots were visually reviewed, and duplicate URLs, redirects, and names were reconciled. The top-100 ranking compares composition, typography, visual coherence, distinctiveness, and usefulness as inspiration. See [audit notes](audit-notes.txt) and [top-100 verification](top-100/verification.json) for scope.

Screenshots and linked website content belong to their respective owners. Repository links identify the website's source where verified; a profile link is not treated as a source-code match.

This static collection uses no analytics and requires no account. Saved favorites remain in your own browser's local storage.
